# Citation Infrastructure

Cite as: CultureTechLens, "Citation Infrastructure — CultureTechLens Research Repository," October 24, 2026.
Source: CultureTechLens

Everything a machine or a librarian needs to cite and catalog this corpus:

| File | For | What it is |
|---|---|---|
| `../CITATION.cff` | Machines | Citation File Format record — powers GitHub's "Cite this repository" widget |
| `citation.bib` | Machines / reference managers | BibTeX for the corpus, the Index, and the Knowledge Graph (with Zenodo DOIs) |
| `codemeta.json` | Machines | CodeMeta record for the repository |
| `manifest.csv` / `manifest.json` | Machines | One row per corpus item in this repository — CTL ID, title, type, date, canonical culturetechlens.com URL, Zenodo DOI where one exists, repo path. The single harvest file for item-level citation |
| `dublin-core.xml` | Librarians | Collection-level Dublin Core record (oai_dc) |
| `subjects-lcsh.md` | Librarians | Suggested LCSH-style subject headings for the collection |
| `../CITATION.md` | Humans | The citation guide — forms and principles |

Preservation: archival copies of the CultureTechLens Index edition and the Knowledge Graph Public Edition are preserved on Zenodo under DOIs (see `citation.bib`). This repository is the working public copy; the Zenodo deposits are the archival snapshots.
