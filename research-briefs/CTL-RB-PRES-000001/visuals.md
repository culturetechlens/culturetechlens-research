## A. Data graphics (build at publish time)

These are original data-driven graphics built from the brief's own verified institution table. They are the safest visual class: no third-party rights, no privacy risk (institution/public-building level only).

### VG-1 — Institution / access-status matrix
- **Type:** data-graphic-build · **Status:** build-at-publish
- **Content:** Rows = profiled institutions (CPL/Harsh, Chicago History Museum, DuSable, UChicago SCRC, Newberry, Northwestern, UIC, Chicago State, Columbia College Chicago, Roosevelt, South Side Community Art Center, Shorefront Legacy Center, Cook County Archives, Rebuild Foundation). Columns = collection scope, coverage dates, finding-aid status, digitization status, current access status (open / appointment / temporarily closed / closed).
- **Explanatory context:** Makes access disparities visible at a glance — the core argument of the brief.
- **Build instructions:** Horizontal matrix; access status color-coded (gold = open, deep red = closed/temporarily closed, grey = appointment-only); footnote every cell with its claim-ledger ID; non-sensitive institutional names only.

### VG-2 — Non-sensitive institutional map
- **Type:** data-graphic-build · **Status:** build-at-publish
- **Content:** Point map of Chicago with markers at public institution/building level only (Woodson Regional Library, Harold Washington Library Center, Chicago History Museum, DuSable Museum, etc.).
- **Privacy rule:** Markers at public buildings only; private collections described no more precisely than neighborhood level and never pinned.
- **Build instructions:** Base map of Chicago community areas; gold markers for open/appointment repositories, deep-red markers for temporarily closed ones; legend included.

### VG-3 — Memory-chain diagram
- **Type:** data-graphic-build · **Status:** build-at-publish
- **Content:** CREATED → RECORDED → COLLECTED → CATALOGED → PRESERVED → DIGITIZED → CONNECTED → DISCOVERABLE → USED → TRANSMITTED, with documented breakpoints annotated (e.g., unprocessed backlogs at the DIGITIZED/CATALOGED stages; the current Harsh building-maintenance closure at the USED stage).
- **Build instructions:** Horizontal flow; breakpoints flagged with claim-ledger citations.

### VG-4 — Institutional founding / access timeline
- **Type:** data-graphic-build · **Status:** build-at-publish
- **Content:** Timeline from the 19th century to present: collection foundings and key access events (Harsh Collection founded 1932; BMRC launched July 1, 2006; Harsh temporary closure 2026, targeting November reopening).
- **Build instructions:** Single horizontal axis; events with claim-ledger citations; CTL black/deep-red/gold palette.
